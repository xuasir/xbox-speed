# 诊断与验收

LuCI 的“环境检测”提供快速初查、后台完整验收、历史验收查看及脱敏报告下载。运行状态区显示最近完整测速和最近活动，运行日志页提供分组结果、应用状态、时间、退出码和持久保存警告。

## 任务与错误

后台请求返回 `accepted` 和 `task_id`，任务进入 `queued → running → 终态`。终态包括 `success`、`partial`、`failed`、`cancelled`、`skipped` 和 `interrupted`；每组测速及应用验收有独立结果。摘要仍为运行状态而对应进程已消失时，读取端标为 `interrupted / PROCESS_MISSING`。

命令行测速和 `check` 使用以下退出码：

| 退出码 | 含义 |
|---|---|
| 0 | 请求动作完成，具体适用范围见分组与验收结果 |
| 1 | 测速、配置、应用或明确的验收项失败，也用于请求的测速功能全部关闭 |
| 2 | 部分测速成功，或验收仍有警告、未知项 |
| 124 | 服务操作超过期限，等待的子进程已终止；清理记录保留 |
| 130 | 任务取消 |

curl 错误同时记录 HTTP、退出码、字节、耗时和原始错误摘要。常见代码及处理：

| 代码 | 处理建议 |
|---|---|
| `DNS_RESOLVE_FAILED` | 检查上游 DNS 和域名 |
| `CONNECT_FAILED` | 结合原始错误检查节点、路由和防火墙 |
| `TIMEOUT` | 检查连接耗时、总耗时及下载字节，确认连接或传输阶段 |
| `TIME_LIMIT_WITH_DATA` | 已取得足够的 206 样本，可用于测速排名 |
| `HTTP_NOT_FOUND` / `RANGE_INVALID` | 检查该节点的测试资源与起始偏移 |
| `HTTP_FORBIDDEN` | 检查 Host 与节点资源兼容性 |
| `RANGE_IGNORED` / `INSUFFICIENT_DATA` | 检查 Range 支持及实际返回的数据量 |
| `INVALID_SPEED` | curl 速度缺失或为零，重新测量 |
| `FIREWALL_UNREADABLE` / `FIREWALL_PARTIAL_READ` | 检查工具与读取权限，当前入口状态待确认 |
| `SERVICE_TIMEOUT` | 检查 `ps w` 与服务锁持有进程；旧版锁泄漏按[恢复步骤](UPGRADE_LOCK_RECOVERY.md)处理 |
| `SERVICE_STOP_INCOMPLETE` | 根据实际解析进程的二进制、配置路径和状态检查停用结果 |

`/etc/init.d/xbox-accel stop`、`shutdown`、`disable` 默认期限为 60 秒，启动、重启、重载和开机恢复为 120 秒；超时清理可能额外耗时约 1 秒。停止后会查验实际解析进程，覆盖 procd 注册信息与 PID 文件遗失的情况。服务清理错误会保留失败退出码，重启在停止失败时中止。

## 完整验收范围

验收分别汇总路由器链路、测试资源、直连集合，另列实际流量与 Xbox 待确认状态。资源校验失败或直连集合缺少应有节点会进入任务失败结果；查询超时等未知项进入部分完成结果。

启用的下载域名、四个备用 CDN 和三个 SRV 名称会按当前模式逐项检查。独立解析实例、主 DNS 和最多三个已识别的 DNS 重定向入口分别查询 A、AAAA、SRV，每项展示预期与实际值。超过入口上限、DNAT 目标待解析、域名兼容性失败以及功能关闭均明确列出范围。

`psw_white` 成员检查提供集合配置证据。Xbox 实际路径需要客户端观测：

1. 在 Xbox 所在网络确认实际使用的 DNS，读回对应下载域名，核对选中地址与 AAAA 状态。
2. 开始下载后观察实际目标 IP、Passwall 规则命中和代理流量，确认本次连接的分流路径。
3. 下载同一游戏，对比启用前后的稳定速度；节点变更后暂停并继续下载，使新连接使用新的解析结果。

## 持久记录与导出

| 路径 | 内容与保留方式 |
|---|---|
| `/tmp/xbox-accel/activity.log` | 本次开机日志，任务结束后保留 500 行 |
| `/etc/xbox-accel/activity-last.log` | 上次任务结束时的快照，最多 500 行及 128 KiB |
| `/etc/xbox-accel/last-task.json` | 最近活动摘要 |
| `/etc/xbox-accel/last-speed-task.json` | 最近完整测速摘要，健康检查及报告导出分别记录 |
| `/etc/xbox-accel/last-application.json` | 最近完整验收及检测配置签名 |
| `/tmp/xbox-accel/diagnostic-report.json` | 经过 JSON 文件校验的脱敏导出报告 |

持久文件原子替换并使用私有权限。日志快照仅在任务结束时更新，运行中突然断电时可保留此前完成任务的日志与当前任务开始记录。存储写入失败会在摘要中提示；“清空日志”清除内存日志及持久日志快照，任务摘要继续保留。

报告只收集插件配置白名单、任务及验收记录和插件日志。地址使用一致别名，URL 路径和参数隐藏，URL 认证信息移除；代理配置、Wi-Fi 密码及系统设备标识均在收集范围之外。导出成功表示报告已生成，各层检测结论保留原始状态。分享前检查报告内容。
